
# Interactive Solar System 

It shows the solar system with the sun in the center and planets moving around it.  
I used **HTML, CSS, and JavaScript** to build it.

## What it does
- Planets rotate around the sun.
- Hovering on a planet zooms it in.
- Clicking a planet opens an info panel with details.
- Saturn has rings made with CSS.


## Files
- `index.html` → main page
- `style.css` → design and animations
- `script.js` → interactivity and info panel
